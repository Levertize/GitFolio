Problem Statement
Masalah yang diselesaikan
Fresh graduate sering kesulitan membuat portfolio web yang terlihat profesional karena butuh waktu, skill desain, dan setup yang ribet. Padahal semua data coding mereka sudah ada di GitHub — hanya belum divisualisasikan dengan baik. GitFolio mengambil data GitHub secara otomatis dan mengubahnya menjadi portfolio yang beautiful + dashboard coding yang informatif, tanpa perlu coding manual.
Target User
FG
Fresh Graduate / Junior Developer

Punya repo GitHub aktif, belum punya portfolio web yang proper. Mau cari kerja / freelance tapi males setup portfolio dari scratch. Senang pamer progress coding ke teman dan recruiter. Tech-savvy tapi bukan designer.

Core Features
GitHub Integration MUST
Login via GitHub OAuth. Auto-fetch repos, commit history, contribution graph, languages used, dan stats lainnya dari GitHub API. Zero manual input dari user.
Beautiful Portfolio Page MUST
Public page yang bisa di-share ke recruiter. Menampilkan: bio, top repos dengan preview, language breakdown, contribution heatmap, dan project highlights. URL unik per user: gitfolio.app/username.
Coding Activity Graph MUST
Visualisasi interaktif (D3.js) commit activity per hari/minggu/bulan. GitHub contribution heatmap yang lebih cantik dari versi aslinya. Filter by repo, language, time range.
Daily Coding Time V2
Integrasi WakaTime API untuk menampilkan waktu coding harian per bahasa dan project. Dashboard produktivitas personal.
Dev Notes / Journal V2
Fitur daily notes untuk logging apa yang dikerjakan hari ini. Auto-link ke commit pada hari yang sama.
Share & Pamer Mode MUST
Satu-klik generate shareable image (OG card) dari stats coding kamu — siap di-post ke LinkedIn atau Twitter/X. Streak counter, total commits, languages leaderboard.
